# 班級遊戲達標解鎖

後台入口：`/admin/game-unlocks`。規則以班級為單位，學生進入首頁時依 `game_records` 即時計算。

## 規則內容

- 來源遊戲：可複選，符合條件的紀錄合併計算。
- 教材範圍：可使用全部範圍，或指定版本、冊別、單元。
- 達標方式：完成次數、最高分、任一達成、兩者皆達成。
- 目標遊戲：未達標前鎖定；達標後在一般時段加入可玩範圍。
- 上學時段白名單及全校停用設定仍有較高優先權。

完成次數會兼容兩種存檔方式：一局一筆的紀錄直接計數；採用同筆更新的遊戲則讀取 `attempt_number`，避免低估次數。

## 個別覆寫

每一條班級規則都可對個別學生設定：

- 沿用班級
- 強制解鎖
- 強制鎖定
- 自訂次數及分數門檻
