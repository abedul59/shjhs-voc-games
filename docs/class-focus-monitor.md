# 班級專注監控

後台入口：`/admin/focus-monitor`

## 功能範圍

- 教師可對有權限的一般班級或特殊班級啟動監控場次。
- 學生必須已登入且不是匿名使用者；沒有啟動場次時不會寫入監控心跳。
- 啟動後，學生瀏覽器每 15 秒更新目前頁面、分頁可見狀態與最後心跳。
- 學生端每 30 秒重新確認是否有新場次，因此剛啟動後可能需要最多約 30 秒才會出現第一筆資料。
- 教師頁每 5 秒讀取最新狀態，並保留加入、切換分頁、返回、網站內換頁、網路狀態與頁面離開事件。

## 狀態判斷

- 正常停留：心跳未超過警告門檻，且網站分頁可見。
- 切換分頁：瀏覽器回報 `document.visibilityState = hidden`。
- 可能中斷：最後心跳超過警告門檻，預設 45 秒。
- 已離線／可能關閉：最後心跳超過離線門檻，預設 90 秒。
- 尚未進入：本場次還沒有收到該學生的心跳。

瀏覽器被強制終止、裝置斷電或網路突然中斷時，已關閉的程式無法再主動發送訊息。因此「強制關閉」是依最後心跳逾時判定，不應視為能區分斷網、休眠與手動關閉的絕對證據。

## 教師通知

教師必須保持監控頁開啟。按下「啟用聲音與通知」後，學生首次轉為離線狀態時會：

- 在頁面顯示紅色警告；
- 播放提示音；
- 若瀏覽器授權，送出桌面通知。

同一名學生維持離線時不會每 5 秒重複通知；恢復後再次離線才會再通知。

## 資料庫安裝

新資料庫使用：

- `supabase/migrations/20261122_class_focus_monitor.sql`

既有正式資料庫使用：

- `supabase/sql-editor/class_focus_monitor_existing_project_setup.sql`

若資料表尚未建立，學生端會安靜停用心跳，原有登入與遊戲功能不受影響；後台監控頁會顯示安裝提醒。
