# 單字異世界悠閒農莊

這是獨立於「單字開心農場」的單人遊戲。學生從首頁選擇版本、冊數、單元後進入，以所選課程的 `vocabularies` 出題；每次購買、播種、澆水、收成、出售或開拓新區域前都要答對一題英文單字。題型是英文選擇或補兩個英文字母，答錯不執行操作。每題答對 10 分，對錯單字及成績存入既有 `game_records`，會出現在學生歷史紀錄、英雄榜及後台統計。

## 首版內容

- 中央大陸西部起步，完成三次收成並攢到足夠金幣後，可開拓北方與南方。
- 三區各有六塊田地。各區提供兩種作物；作物可澆水催生，成熟後收成並在倉庫出售。
- 金幣、種苗、作物、解鎖區域及開拓日誌儲存在獨立的 `isekai_farm_states` 表，不動用開心農場的資料。
- 視覺採用自行繪製的 SVG 輪廓、羊皮紙問答面板、山脈與農田，沒有直接使用動畫畫面或既有農場美術。

## 啟用

在**新專案**的 Supabase SQL Editor 執行 `supabase/migrations/20261003_isekai_farm.sql` 一次。此腳本只新增獨立存檔表，不修改原本資料。部署後由首頁的「單字異世界悠閒農莊」進入。現站沿用自訂學生 Cookie 與 anon key；RLS 模式與既有農場相同，無法用資料庫權限驗證呼叫者身分。

## 地理與玩法參考

- [《無職轉生》原作中的中央大陸地理描述](https://ncode.syosetu.com/n9669bk/72/)：北、西、南三區與赤龍山脈；西部的小麥、花卉以及南部稻米、油籽等設定。
- [《異世界悠閒農家》動畫官方劇情簡介](https://nonbiri-nouka.com/story/summary/)：從荒野開墾、逐步形成聚落的遊玩節奏參考。
- [公開流傳的世界地圖參考圖](https://i.imgur.com/gYE2lMF.png)：只供輪廓位置參考，沒有直接用作遊戲圖片。遊戲中的地圖是重新繪製的示意圖，並非官方精確地圖。

後續可在這個獨立狀態模型上增加居民、工坊、氣候與城鎮交易，而不影響原有開心農場。
