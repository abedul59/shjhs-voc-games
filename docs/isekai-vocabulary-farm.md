# 單字異世界悠閒農莊

這是獨立於「單字開心農場」的單人遊戲。學生從首頁選擇版本、冊數、單元後進入，以所選課程的 `vocabularies` 出題；首次操作會出題，答題後下一題在 30–40 秒後才會於操作時出現，期間操作直接執行。題型是英文選擇或補兩個英文字母，答錯不執行該次操作。每題答對 10 分，對錯單字及成績存入既有 `game_records`，會出現在學生歷史紀錄、英雄榜及後台統計。

## 遊戲內容

- 首次進入選擇性別、種族、本業職業，以及中央大陸十二塊領地之一作為開局地點。開局只開放所選領地，配發該區作物種苗；完成三次收成並攢到足夠金幣後，可開拓其他區域。既有角色沿用原存檔，不會重設開局地點。五種種族與十六種職業都有實際經營加成；選定後不能直接更改。金幣足夠時可付費轉生，清空農莊重新選擇，學習紀錄保留。種族名稱參考原作，能力與職業組合是本遊戲設計，並非原作設定。
- 大地圖顯示中央大陸全貌；中地圖只顯示目前北、西或南區的四塊領地；小地圖放大所選單一領地，標示當地地形、三處原創地標及農莊；微地圖才顯示農莊與外圍六塊邊境土地。私人農莊內有六個可種植、建設的田位，這六格不是六塊微地圖土地。可將地圖展開至接近全螢幕。全大陸共有十二塊可開拓領地；舊版三區存檔的田地會保留到各區第一塊領地。領地、地標及邊境邊界為遊戲設計，並非原作官方劃分。
- 「超大地圖 · 世界」保留自行繪製的六面世界五大陸示意圖，標出主要王國、城市、迷宮和林古斯海；可點中央大陸進入原有地圖。「超大地圖 · 原圖海岸線」則直接顯示[原作網路小說地圖第 3 版](https://www.baka-tsuki.org/project/index.php?title=File%3AWorld_Map_3.png)的外部原圖，供對照海岸線；圖片載入需連網，並附來源連結。兩者都是地圖展示，其他大陸目前只供瀏覽，農莊玩法仍在中央大陸。
- 三區共提供二十一種作物（新增十五種）；作物可澆水催生，成熟後收成並在倉庫出售。季節和每日天氣影響種植時間與當季收成。新增作物為遊戲原創設定。
- 田地也能建造魔力水井、百獸飼育舍與旅行商棚：水井加快同領地作物生長，商棚提高全農莊售價。飼育頁選擇空田位後可一次建舍並購入動物，畫面顯示合計費用；已有空舍只收動物費。飼育舍每間可養一種生物，依陸地、昆蟲、水生分類，共二十一種（新增十八種）。照顧後等待產物，收取並出售；建築佔用農莊內一格田位，也可付費拆除。新生物是遊戲原創，並非原作物種。
- 金幣、種苗、作物、解鎖區域及開拓日誌儲存在獨立的 `isekai_farm_states` 表，不動用開心農場的資料。
- 視覺採用自行繪製的 SVG 輪廓與不規則田界、羊皮紙問答面板、山脈與農田，以及職業、作物、生物的圖案。沒有直接使用動畫畫面或既有農場美術。

## 人力、家庭與邊境戰

- 人力仲介每三小時輪換候選人，從五種遊戲種族招募，最多八名。每位候選人的種族、職業、擅長工作與戰力不同。可指派農田、飼育、交易或守備；自動工作套用其種族和職業加成。雇用時選日薪或周薪並預付，合約期滿後僅在有工作可做時自動續付；不再逐項扣薪。家人工作按日薪支付。最近紀錄列出實際做過的事。可逐項開關自動播種、澆水、收成、照顧、收取與販賣。
- 有人手或家人工作時，自動開始一輪值班。只計算前景、聚焦且最近一分鐘內曾操作的有效遊玩時間，滿四十五分鐘休息十五分鐘；休息採實際時間，即使關閉頁面也會結束。不需手動重啟。值班每分鐘巡查一次，每人每輪最多完成兩項工作。員工在守備崗位仍參與邊境戰。
- 可參加興趣活動認識對象，或付費相親；約會提高好感，達條件後求婚與結婚。性別不限制配對。新角色可選米里斯或自由信仰；本遊戲設定米里斯最多一位配偶，自由信仰最多三位。舊角色按自由信仰處理。孩子每三小時成長一歲，滿十八歲後每六小時成長一歲；六歲起放學後可工作，未成年不能參戰，成年後可自行交往與結婚。家人工作同樣支付薪資。宗教和婚姻規則是遊戲簡化設計，不代表原作完整規範。
- 每塊領地在私人農莊之外另有六塊同班共享邊境土地。可以挑戰系統守衛或已佔領的同學領主；每回合選擇攻擊、魔術、防禦或道具。戰鬥以主角、可參戰人員的各自能力，以及部分軍事建築效果計算。每塊邊境土地內含 3–6 格田位，格數依土地位置固定產生，重開遊戲不會改變。佔領或租用後，在中央經營畫面的土地選單選取該邊境地，田位會取代私人農莊的六格；可各自種植、建造、拆除、飼育動物、安排人力，以及經營所建設施。邊境戰選單只負責挑戰、租用及切換到取得的土地。舊版邊境地上的單一作物會保留在第一格；原本對應私人田位的收成 +1 保留。佔領沒有時間期限，其他同學仍可在戰勝後奪取；失去歸屬時無法繼續使用該邊境田地，私人農莊與作物不受影響。
- 邊境戰採同人數隊伍：主角加上可參戰的員工、配偶與成年子女；守備崗位優先排列，其他受雇員工與非休息家人也會參加。對方若也是學生，使用其實際人員；系統守軍或人數不足的一方由援軍補足，雙方每場人數相同（遊戲既有上限下最多各 17 人）。每位角色獨立受傷與攻擊，倒下即退出當場戰鬥；魔術、防禦、治療與進攻由玩家每回合決定。此更新需在部署網站所連接的 Supabase 執行 [`20261004_isekai_frontier_party_battle.sql`](../supabase/migrations/20261004_isekai_frontier_party_battle.sql)。
- 空置且未被佔領的邊境地可向系統付 60 金幣租用六小時，到期後需再租才能繼續耕作；租期中可續租，租期結束或地被奪取後未收成的作物失去使用權。佔領起始領地全部六塊邊境地後，可在邊境戰頁選擇中央大陸其他領地，以租用或戰鬥拓展；外部邊境田地不會額外贈送該領地的私人農莊。單字題依 30–40 秒間隔出現。

人物卡與主角預覽使用同一套原創輕量 SVG 立繪，種族、職業與人物代號會改變耳朵、髮型、膚色、衣服和道具。倉庫與日誌可從頁首按鈕展開，區域清單則在地圖下方按需展開。
- 增加石砌穀倉、魔晶溫室、古代水渠、授粉花園、魔鐵工坊、木造瞭望塔、邊境營舍、治療所、魔術講堂與冒險者公會，分別影響收成、生長、照顧、戰鬥或交易。

## 啟用

在**網站實際連接的 Supabase 專案** SQL Editor 依序執行資料庫更新：若尚未建立異世界農莊資料表，先執行下方的首次建置腳本；接著執行 [`20261003_isekai_frontier_farmland.sql`](../supabase/migrations/20261003_isekai_frontier_farmland.sql)，新增租地欄位與函式；最後執行 [`20261004_isekai_frontier_party_battle.sql`](../supabase/migrations/20261004_isekai_frontier_party_battle.sql)，更新同人數隊伍戰鬥。已執行過的步驟不必重複。更新不修改開心農場資料；作物狀態寫入既有農莊 JSON 存檔。部署後由首頁的「單字異世界悠閒農莊」進入。現站沿用自訂學生 Cookie 與 anon key；RLS 模式與既有農場相同，無法用資料庫權限驗證呼叫者身分。正式防止冒用其他學生的借款、互訪、導師設定與邊境操作需要全站改用 Supabase Auth。

### 首次合併到舊專案

舊專案尚未建立異世界農莊資料表時，在**舊專案的 Supabase** SQL Editor 執行 [`isekai_farm_existing_project_setup.sql`](../supabase/sql-editor/isekai_farm_existing_project_setup.sql) **一次**。它依序包含個人存檔、邊境戰、同班借款／互訪及導師權限；不要再逐一執行同名拆分腳本。它不會清除開心農場資料。

程式合併部署後，到後台「前台遊戲分類與排版管理」把「單字異世界悠閒農莊」加入要顯示的分類並儲存；已有自訂分類的網站不會強行插入新遊戲。使用舊站原本的 Supabase URL 與 anon key 即可，無需連向新專案資料庫。開放給學生前，確認學生遊戲可玩權限與導師單元限制的設定。

## 城鎮擴充

- 農莊上方有明顯的「販賣收成」入口；手動收成或取得動物產物後也會開啟倉庫。種苗可一次購入 1–50 份，後端檢查數量與總價。
- 「人力 → 值班與任務」可勾選多種自動播種作物，也可把目前田位標為手動保留；人力不會在該田位補苗或播種。設定會隨農莊進度儲存。
- 農田班優先出售倉庫作物、收成，再對所有已開拓且允許人力播種的空田補買種苗並播種；普通工作每次巡查仍以兩項為限，填滿空田不受此額度截斷。雇用農田人手或修改播種設定後會在下次畫面計時立即巡查，不必先等待一分鐘。飼育班也會出售已收取的產物。現有旅行商棚與角色加成會計入售價。交易班可出售加工品及經營設施。田位標示「手動保留」只阻止自動補苗和播種，不影響澆水或收成；種苗與薪資不足時會在工作紀錄顯示原因。
- 「城鎮」分加工與販賣、商店與觀光、學府與公益、研發與能源、財務與事件。共新增十種加工品、二十六種異世界觀光與商店設施、五種公益機構、魔晶發電陣、屋頂魔晶板、淨水池、研發塔和多族員工宿舍；另新增十二種作物、十種可飼育生物。所有建築佔用自己的農莊田位；城鎮可切換全頁管理。
- 加工坊把兩份作物或生物產物製成一份成品，多族市集提高加工品售價。觀光與商店每三小時可營業一次，週末、天氣、交易員與會計師影響收入。自動人力可在交易職能下加工、賣出與經營設施；任務仍可逐項關閉。
- 公益機構在已建的自有地上成立；創辦捐款及後續收入留在專用基金，不能提回農莊。可聘主管與專業人員，設定學府班級與招生、調整週課表、擴建校園或其他設施。機構有員工和足夠基金時每三小時自動營運，亦可手動營運。
- 研發指定作物最多三級，每級增加收成並縮短生長時間。魔晶板前三處有補助，晴天發電較多；發電、水費、專家薪資和季節事件每三小時結算，明細在帳本。會計師、契約法律顧問和異獸醫師獨立聘用。
- 金幣低於 50 時可向公會申請 200 金幣六小時零息急難借款。同班借款需另一片全空的已開拓領地作抵押；同學同意後撥款，六小時內還本付 10% 利息，逾期在任一當事人上線時由資料庫原子結算並賣出抵押領地，餘款還給借款者。
- 導師後台的「農場遊戲可玩範圍」可切換開心農場或異世界農莊，分別設定班級白名單／黑名單；首頁與異世界農莊頁都會檢查設定。
- 同班互訪顯示對方目前領地、累積收成與倉庫作物；每三小時最多取得同一位同學一份收成。資料庫函式檢查同班、庫存與冷卻，並原子更新雙方存檔；互訪有獨立紀錄。
